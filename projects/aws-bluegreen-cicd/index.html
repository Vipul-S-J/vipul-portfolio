AWS Blue/Green CI/CD Automation

Deployment automation for a production web application on AWS: a git push builds an artifact on a self-hosted GitLab Runner, stores it in S3, and AWS CodeDeploy rolls it out with a blue/green deployment onto an Auto Scaling Group that mixes Graviton and x86, On-Demand and Spot capacity.

  • CodeDeploy
  • GitLab CI/CD
  • Auto Scaling

View on GitHub

Architecture: Blue/green deployment path

  1. A git push to GitLab triggers the pipeline.
  2. The self-hosted GitLab Runner on EC2 builds and packages the app.
  3. The artifact is uploaded to an S3 bucket.
  4. CodeDeploy pulls the artifact from S3 and starts a blue/green deployment.
  5. A green fleet is provisioned by copying the Auto Scaling Group.
  6. The Application Load Balancer shifts traffic from blue to green.
  7. After a successful deployment the blue fleet is terminated (0-minute wait).

Design decisions

  • S3-based delivery instead of CodeDeploy's native Git integration: GitLab CI builds and zips the app, uploads it to S3 under a fixed naming convention, and CodeDeploy pulls it from there.
  • A diverse instance mix (Graviton and several x86 families) widens the Spot capacity pools AWS can draw from, which improves availability and reduces interruptions.
  • price-capacity-optimized Spot allocation picks the pools with the most available capacity at the best price, lowering interruption risk.
  • Scaling follows demand: target tracking scales out when average requests per target exceed the target and scales in when demand drops.

What is in the repository

  • .gitlab-ci.yml: build, upload and deploy stages, including the aws deploy push to S3
  • appspec.yml: CodeDeploy lifecycle hook mapping
  • Asg-mixed-instance-policy.json: the mixed-instances policy (Graviton + x86, Spot)
  • aws-cd/: lifecycle scripts (after_install, application_start, validate_service, after_block_traffic, update_lifecycle_hook)
  • docs/: CodeDeploy and GitLab setup guides. Account IDs, bucket and load balancer names are generic placeholders.
