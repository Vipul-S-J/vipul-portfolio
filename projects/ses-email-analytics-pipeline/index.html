SES Email Analytics Pipeline

A serverless pipeline that captures Amazon SES email events in near real time, streams them through Amazon Kinesis Data Firehose into S3, and makes them queryable with Athena, so email engagement and deliverability can be analysed with SQL and no servers to manage.

  • SES
  • Kinesis Firehose
  • Athena
  • CloudFormation
View on GitHub

Architecture: Event pipeline

  1. A configuration set is assigned to a verified SES identity (domain or email).
  2. SES publishes the selected event types to a Firehose delivery stream.
  3. Firehose buffers records and writes newline-delimited JSON to S3, partitioned by date.
  4. Athena reads the data through an external table, so it can be queried with standard SQL.

Design decisions

  • Serverless from end to end: SES, Firehose, S3 and Athena leave no servers to patch or scale.
  • CloudFormation is the recommended way to deploy; a console walkthrough covers the same steps.

What is in the repository

  • cloudformation/ses-analytics-pipeline.yaml: the stack
  • athena/create_table.sql and athena/sample_queries.sql: the external table and example analytics queries
  • docs/setup-guide.md: step-by-step console walkthrough
